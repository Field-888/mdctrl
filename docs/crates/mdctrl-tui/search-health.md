# 搜索、健康与跳转

> 文档状态：草案 · 最后复核：2026-11-14

> 三个界面共享一套会话模型：先得到候选集合，再选中，再跳转；数据始终来自 server。

> 阶段边界：文件名查找、全文搜索、反链与跳转属于 MVP1；健康面板与健康结果展示属于 MVP2，MVP1 只保留入口占位。

**相关文档**：[mdctrl-tui](README.md) · [视图状态](view-state.md) · [事件循环](event-loop.md) · [mdctrl-cli](../mdctrl-cli/README.md)

## 1 职责划分

| 能力 | 数据来源 | TUI 职责 |
| --- | --- | --- |
| 文件名查找 | server 的文件索引或工作区概览 | 输入、过滤、展示、跳转 |
| 全文搜索 | server 的 index service | 发送 query、展示命中与上下文 |
| 健康检查 | server 的 health service | 展示问题、过滤、跳转 |
| 反链与大纲 | server 的链接图与结构 | 展示、跳转 |
| 跳转 | server 解析路径与锚点 | 维护导航栈与定位 |

TUI 不实现分词、评分与健康规则。模糊匹配若在 client 侧完成，只作为对 server 结果集的再过滤，不改变权威结果。

## 2 搜索会话模型

```rust
struct SearchSession {
    kind: SearchKind,
    query: String,
    results: Vec<SearchHit>,
    selected: usize,
    loading: bool,
    error: Option<SearchError>,
}

enum SearchKind {
    FileName,
    FullText,
    Backlink,
}
```

规则：

- 输入变化触发去抖查询，避免每次按键都请求；
- 查询带会话标识，过期响应丢弃；
- 结果按稳定顺序排列，选中项在结果更新后尽量保持；
- 无结果时显示空状态与可执行提示；
- 搜索会话关闭后清空结果，不常驻内存。

## 3 文件名查找

- 输入路径片段或文件名，返回候选路径；
- 结果展示相对工作区根的路径，命中片段高亮；
- 默认限制返回数量，超出时提示继续输入；
- 目录与文件使用不同图标或标记；
- 回车打开选中项，`Tab` 预览，`Esc` 关闭。

文件名查找优先使用 server 提供的工作区概览；client 侧只做增量过滤与展示。

## 4 全文搜索

- 查询发送到 server，返回命中、行号、片段与高亮范围；
- 结果按文档分组，支持展开与折叠；
- 中文查询依赖 server 的分词与索引，client 不假设词边界；
- 展示命中数量与截断状态；
- 打开命中后定位到对应行，并保留搜索会话以便返回；
- 搜索过程中显示进度，允许取消。

## 5 健康界面

健康数据包含四类问题：断链、孤儿文档、过期文档、缺失元数据。

| 列 | 内容 |
| --- | --- |
| 严重度 | 错误、警告、提示 |
| 规则 | 规则标识与简述 |
| 位置 | 文档路径与行号 |
| 消息 | 可读描述 |
| 操作 | 跳转、忽略（后续阶段） |

交互规则：

- 按严重度或规则过滤；
- 选中项显示详情与相关文档；
- 跳转打开目标文档并高亮位置；
- 刷新由显式命令或 event 触发，不自动轮询；
- 空结果显示“未发现问题”与检查范围。

## 6 跳转与导航栈

```rust
struct NavigationStack {
    entries: Vec<Location>,
    index: usize,
}

struct Location {
    path: DocumentPath,
    position: SourcePosition,
    scroll: ScrollState,
}
```

规则：

- 跳转前把当前位置压入栈；
- 前进与后退在栈内移动，不重复压栈；
- 目标文档加载失败时保留当前视图并提示；
- 锚点无法解析时打开文档顶部并提示；
- 文档版本变化后，按源位置近似定位，不保证精确到字符；
- 导航栈深度有限，超出丢弃最旧项。

## 7 键位建议

| 场景 | 键位 |
| --- | --- |
| 打开文件名查找 | `Ctrl+P` 或 `f` |
| 全文搜索 | `/` |
| 下一个/上一个命中 | `n` / `N` |
| 打开健康面板 | `h` 或 `Ctrl+H` |
| 跳转 | `Enter` |
| 预览 | `Tab` |
| 返回 | `Ctrl+O` |
| 前进 | `Ctrl+I` |
| 关闭 | `Esc` |

键位可由用户覆盖；表内为默认值，冲突在启动时检测并提示。

## 8 与 CLI 的一致性

TUI 的健康与搜索语义必须与 CLI 对齐：

- 相同的健康规则与严重度；
- 相同的排序与截断策略；
- 相同的空状态与错误分类；
- CLI 的结构化输出字段是 TUI 展示字段的子集。

对应命令与输出格式见[CLI 数据命令](../mdctrl-cli/data-commands.md)。

## 9 错误与边界

- server 未就绪：显示“索引未建立”，提供触发入口；
- 查询超时：保留旧结果并提示，不阻塞输入；
- 结果过大：分页或限制数量，提示缩小范围；
- 路径越界：拒绝跳转并提示工作区边界；
- 文档已删除：从结果中移除并提示。

## 10 测试关注点

- 搜索会话的状态迁移与去抖行为；
- 过期响应丢弃；
- 空结果、超时与错误展示；
- 健康过滤与跳转定位；
- 导航栈前进/后退边界；
- 中文查询在两字与多字场景下的展示。
