# 栅格化

> 文档状态：草案 · 最后复核：2026-11-14

> View 是语义快照，Cell Grid 是终端事实：栅格化只做映射，不做重新排版。

**相关文档**：[mdctrl-tui](README.md) · [视图状态](view-state.md) · [主题与 CJK](theme-cjk.md) · [技术选型](../../techStack.md#5-终端渲染与-tui)

## 1 View 消费

View 由 server 生成，包含当前视口的结构化内容：

| 字段 | 内容 | client 用途 |
| --- | --- | --- |
| document | 路径与文档版本 | 校验与缓存键 |
| viewport | 可见范围与宽度 | 匹配窗格尺寸 |
| blocks | 块级元素与行信息 | 生成 Cell 行 |
| styles | 语义样式 token | 映射终端样式 |
| spans | 行内片段与源位置 | 选择、跳转、光标 |
| media | 媒体占位与资源引用 | 图片、公式、Mermaid |
| diagnostics | 诊断与生命周期提示 | 标记与提示 |

client 的栅格化输入固定为：View、窗格矩形、终端能力、主题映射。输出是 Cell Grid 与光标位置。

本节字段、JSON 字段与规则 id 均为候选契约：`mdctrl-protocol` 尚未实现这些类型，需 `field` 确认 View 与协议形状、`ylgd0915` 确认健康与索引字段后固化。

规则：

- View 的路径必须匹配当前文档，请求代次必须匹配当前代次；
- 首次加载接受第一个响应，并原子建立版本与缓存；
- `latest` 请求接受 server 当前版本，版本变化时清空选择并夹紧滚动；
- `exact` 请求只接受同版本响应；返回更新版本时丢弃并按 `latest` 重新请求；请求模式定义见[视图状态](view-state.md#5-与-server-视图对齐)；
- View 宽度必须匹配请求宽度，否则按[窗格布局](layout.md)重新请求；
- 不完整 View 只绘制完整行，不推测缺失内容；
- 源位置随 span 保留，用于选择与跳转；
- 未识别的样式 token 使用默认样式并记录诊断。

## 2 Cell Grid

Cell Grid 是窗口大小的二维缓冲区：

```rust
struct Cell {
    grapheme: Grapheme,
    style: CellStyle,
    width: u8,        // 1 或 2
    continuation: bool,
}
```

规则：

- 一个 Cell 保存一个字素簇，不拆分组合字符；
- 宽字符占两个 Cell，后一格标记为 continuation；
- 每帧缓冲必须完整表示当前画面：未写入区域填空白，宽字符变窄时清除旧的 continuation Cell；
- 增量输出可以跳过未变化区域，但逻辑缓冲不得依赖上一帧残留内容；
- 样式只保存语义解析后的终端样式，不保存 token；
- 光标位置与 Cell 坐标一一对应。

## 3 栅格化步骤

```text
View
  → 行模型（每行的 span 序列）
  → 宽度计算（字素簇 + 显示宽度）
  → 样式解析（token → 终端样式）
  → 写入 Cell Grid
  → 脏行 diff
  → 后端输出
```

每一步保持纯函数：相同的 View、尺寸、主题与能力产生相同的 Cell Grid，便于快照测试。

## 4 宽字符与换行

- 宽度计算以字素簇为单位，使用 Unicode 宽度数据；
- 全角标点按宽度 2 处理；
- emoji 按终端显示宽度处理，优先使用宽度 2；
- 零宽连接符序列不拆分；
- 文档断行与标点避头尾由 server 完成，每行宽度不超过请求宽度，client 不重新排版；
- 宽字符放不下当前视口剩余列时，client 不拆分字素簇：裁掉整个字素簇并标记截断，同时按宽度不匹配重新请求 View；
- 截断发生在字素簇边界，并追加省略符；
- 本地界面标签（按钮、状态栏、面板标题）的换行由 client 负责，与文档 View 的断行规则分离。

## 5 样式映射

View 提供语义 token，client 映射为终端样式：

| token 类别 | 示例 | 映射 |
| --- | --- | --- |
| 前景 | 正文、次要、强调、错误 | 终端颜色或默认色 |
| 背景 | 页面、代码、选中、提示 | 终端颜色或默认背景 |
| 修饰 | 粗体、斜体、下划线、删除线 | 终端修饰 |
| 边框 | 窗格、聚焦、分隔 | 前景色 |
| 状态 | 成功、警告、错误、信息 | 颜色对 |

映射规则与小节见[主题与 CJK](theme-cjk.md)。

## 6 终端能力与降级

能力探测结果决定渲染路径：

| 能力 | 探测方式 | 降级 |
| --- | --- | --- |
| 颜色数 | `TERM`、`COLORTERM`、能力查询 | 256 色 → 16 色 → 单色 |
| 真彩色 | `COLORTERM=truecolor` 等 | 近似到调色板 |
| 背景色 | OSC 11 查询 | 超时使用默认主题 |
| 同步输出 | 能力查询 | 逐帧刷新 |
| 鼠标 | 终端支持 | 仅键盘 |
| 图片协议 | kitty、sixel、iTerm2 查询 | 半块字符 → 占位文本 |
| 备用屏幕 | 终端支持 | 主屏幕绘制并保存/恢复 |

探测失败不阻塞启动；使用保守默认值，并在诊断中记录探测结果。

## 7 增量刷新

- 只输出脏行，未变化行跳过；
- 脏行按连续区间合并，减少转义序列；
- 光标移动与样式切换合并为一次输出；
- 同步输出可用时整帧包裹在同步区间内；
- 大范围变化（resize、主题切换）按全量重绘处理；
- 输出失败视为终端断开，进入退出路径。

## 8 媒体占位

- 公式、Mermaid 与图片先绘制占位块；
- 占位块保留原始尺寸与位置，避免就绪后重排；
- 资源就绪事件到达后，只重绘受影响的 Cell 区域；
- 图片协议不可用时显示替代文本或源码；
- 图片解码与缩放不在渲染线程阻塞输入，使用预解码结果。

## 9 性能预算

| 场景 | 目标 |
| --- | --- |
| 普通滚动 | 每帧只栅格化可见行与相邻少量行 |
| 大文档 | 不持有完整 Cell Grid，仅窗口大小 |
| 宽字符密集 | 字素簇宽度缓存，避免重复计算 |
| 连续 resize | 去抖后只按最终尺寸请求一次 View |
| 媒体替换 | 只重绘局部区域 |

## 10 测试关注点

- Cell Grid 快照：CJK、emoji、组合字符、宽窄混合；
- 样式映射快照：主题与颜色能力组合；
- 降级矩阵：无颜色、无图片、无同步输出；
- 增量刷新：脏行 diff 的输出序列；
- 尺寸变化：重新请求与缓存失效。

测试后端与夹具见[测试](testing.md)。
