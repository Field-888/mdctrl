# 窗格布局

> 文档状态：草案 · 最后复核：2026-11-14

> 三栏是默认形态，不是唯一形态：窗格布局由 client 计算，文档内部布局由 server 提供。

**相关文档**：[mdctrl-tui](README.md) · [视图状态](view-state.md) · [主题与 CJK](theme-cjk.md) · [架构](../../architecture.md#9-渲染架构)

## 1 职责边界

| 布局 | 所有者 | 内容 |
| --- | --- | --- |
| 窗格布局 | client | 导航、文档、上下文三栏，状态栏与面板 |
| 文档布局 | server | 段落、列表、表格、代码块的换行与缩进 |
| 终端栅格 | client | Cell 坐标、样式与光标 |

client 只决定“把哪个 View 放到哪个矩形里”，不重算文档内部的换行。server 的布局树以视口宽度为输入；窗格尺寸变化时，client 以新宽度重新请求 View。

## 2 默认三栏

```text
┌──────────────┬────────────────────────────┬──────────────┐
│ 导航         │ 文档                       │ 上下文       │
│ 文件树       │ 标题、正文、代码、表格     │ 大纲         │
│ 搜索入口     │                            │ 反链         │
│              │                            │ 健康         │
├──────────────┴────────────────────────────┴──────────────┤
│ 状态栏：路径 · 位置 · 模式 · 文档版本 · 连接状态          │
└──────────────────────────────────────────────────────────┘
```

| 窗格 | 内容 | 默认宽度 |
| --- | --- | --- |
| 导航 | 文件树、搜索入口、视图切换 | 24–32 列 |
| 文档 | 当前 View 与占位、选择、光标 | 自适应 |
| 上下文 | 大纲、反链、健康、文档元数据 | 28–36 列 |
| 状态栏 | 路径、行号、模式、提示、连接 | 1–2 行 |

## 3 响应式断点

| 可用宽度 | 形态 | 说明 |
| --- | --- | --- |
| ≥ 120 列 | 三栏 | 默认形态 |
| 80–119 列 | 两栏 | 上下文收为可切换面板 |
| 60–79 列 | 单栏 + 状态栏 | 导航与上下文通过页签切换 |
| < 60 列 | 单栏精简 | 隐藏次要信息，保留文档与提示 |

断点按可用宽度计算，不含边框与状态栏。高度不足时优先保留文档与一行状态：高度小于 5 行时隐藏状态栏，小于 3 行时只显示最小提示。切换断点时：

- 文档窗格优先保留；
- 焦点若落在被隐藏的窗格，转移到文档窗格；
- 隐藏窗格的展开状态保留，恢复宽度时还原；
- 丢弃按旧宽度生成的 View 缓存。

## 4 尺寸计算

- 边框使用单线字符，宽度计入窗格；
- 内边距固定，不随宽度缩放；
- 文档窗格宽度传给 server 作为布局输入；
- 状态栏高度固定，内容超长时截断并保留模式与连接状态；
- 最小宽度不足时先压缩上下文，再压缩导航，最后降级为单栏；
- 宽字符与 emoji 按终端显示宽度计算，截断不拆分字素簇。

## 5 焦点与导航

焦点顺序固定为：导航 → 文档 → 上下文 → 状态栏交互区。

规则：

- `Tab` / `Shift+Tab` 在窗格间移动焦点；
- 焦点窗格有可见边框与标题强调；
- 关闭窗格后焦点回到文档；
- 覆盖层打开时焦点进入覆盖层，关闭后回到进入前的位置；
- 鼠标点击窗格直接切换焦点，滚轮作用于指针所在窗格。

## 6 面板与覆盖层

面板是窗格内的可切换内容，覆盖层是浮在布局之上的临时界面：

| 类型 | 示例 | 归属 |
| --- | --- | --- |
| 面板 | 大纲、反链、健康、元数据 | 上下文窗格 |
| 覆盖层 | 搜索、命令面板、确认、错误详情 | 全屏居中 |
| 内联提示 | 状态栏消息、进度 | 状态栏 |

覆盖层规则：

- 覆盖层不改变底层布局尺寸，只影响绘制与输入；
- 同一时刻最多一个覆盖层；
- 覆盖层提供关闭键与显式取消；
- 危险操作（退出、放弃修改）使用确认覆盖层。

## 7 滚动与视口

- 文档窗格维护垂直滚动，必要时支持水平滚动；
- 导航与上下文窗格独立滚动；
- 滚动以行为单位，宽字符行按显示宽度处理；
- 视口高度等于窗格内容区高度；
- 滚动到边界时请求相邻视口，预取范围有限；
- 跟随光标时保持光标可见，用户手动滚动后暂停跟随。

## 8 不变量

- 所有窗格矩形不重叠，且完全落在终端范围内；
- 正常布局（可用宽度 ≥ 40 列且高度 ≥ 5 行）下状态栏始终可见，文档窗格宽度不小于 40 列；
- 低于上述尺寸进入极小尺寸降级：取消文档最小宽度约束，只保留单栏与一行提示，按实际宽度请求 View；
- 可用宽度小于 1 列或高度小于 1 行时无法渲染，显示最小提示并等待 resize；
- 焦点始终落在可见窗格或覆盖层；
- 布局计算不分配与终端尺寸无关的缓存；
- 布局变化使相关 View 请求失效，不直接复用旧宽度结果。

## 9 持久化与配置

| 配置 | 作用域 | 默认 |
| --- | --- | --- |
| 窗格可见性 | 本机 | 三栏可见 |
| 窗格宽度 | 本机 | 导航 28、上下文 32 |
| 状态栏位置 | 本机 | 底部 |
| 鼠标支持 | 本机 | 开启 |

工作区不保存个人布局偏好；团队共享的展示约定由文档约定，不进入客户端配置。

## 10 测试关注点

- 断点切换的布局快照；
- 最小宽度与窄终端降级；
- CJK 与 emoji 的截断位置；
- 焦点转移与覆盖层回退；
- 窗格尺寸变化触发 View 重新请求。
