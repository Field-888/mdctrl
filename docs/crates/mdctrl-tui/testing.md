# 测试

> 文档状态：草案 · 最后复核：2026-11-14

> TUI 的可测试性来自三件事：纯函数栅格化、可注入的协议通道、可记录输出的测试后端。

> 本文是 MVP0 的测试计划；对应功能与测试在后续 MVP 实现，不在本次文档任务范围内。

**相关文档**：[mdctrl-tui](README.md) · [栅格化](rasterization.md) · [事件循环](event-loop.md) · [贡献指南](../../../CONTRIBUTING.md#5-本地检查)

## 1 测试层次

| 层次 | 对象 | 工具 |
| --- | --- | --- |
| 单元 | 键位映射、宽度计算、状态迁移、布局计算 | `cargo test` |
| 属性 | 宽度计算、截断与字素簇边界 | `proptest` |
| 快照 | Cell Grid、窗格布局、主题映射 | `insta` + 测试后端 |
| 契约 | View 消费、协议消息处理 | 固定夹具 |
| 集成 | 事件循环 + 模拟 server | 内存通道 |
| 手工 | 真实终端能力、图片协议、背景探测 | 终端矩阵 |

## 2 测试后端

- 使用 `ratatui` 的 `TestBackend` 或等价的可记录后端；
- 后端暴露缓冲区快照，断言 Cell 内容、样式与光标位置；
- 测试不依赖真实 TTY，不读写用户终端状态；
- 终端能力作为显式参数注入，不在测试中探测环境；
- 时间与超时通过可注入时钟控制，避免真实等待。

## 3 夹具

| 夹具 | 用途 |
| --- | --- |
| View 最小样例 | 段落、标题、列表 |
| View 复杂样例 | 表格、代码块、引用、callout |
| View 宽字符样例 | 中文、全角标点、emoji、组合字符 |
| View 诊断样例 | 断链、过期、缺失元数据 |
| View 媒体样例 | 公式与 Mermaid 占位 |
| 事件序列 | 输入、resize、断线、重连 |

夹具以结构化数据保存，不依赖 server 实现；字段变化时先更新夹具再更新断言。

## 4 单元与属性测试

- 键位映射：每个模式的默认键位与冲突检测；
- 状态迁移：模式切换、覆盖层回退、导航栈边界；
- 布局计算：断点切换、最小宽度、焦点转移；
- 宽度计算：对随机字符串断言总宽度等于逐字素宽度之和；
- 截断：断言不拆分字素簇、省略符不超宽；
- 滚动：断言视口始终落在有效范围。

属性测试的失败用例保存为回归夹具。

## 5 快照测试

- 快照覆盖固定终端尺寸与能力组合；
- 快照文件随代码评审，变更说明原因；
- 快照只包含 Cell Grid 的稳定表示，不含转义序列细节；
- 主题快照按 token 映射验证，不依赖终端配色；
- 宽字符快照检查对齐与截断位置。

快照更新使用 `cargo insta review`；CI 中禁止自动接受快照。

## 6 契约测试

- 给定 View 与视口，断言栅格化结果符合预期；
- `exact` 请求的版本不匹配 View 被拒绝；`latest` 请求接纳新版本并清空选择、夹紧滚动；
- 视口宽度不匹配的 View 触发重新请求；
- 未识别 token 使用默认样式并产生诊断；
- 过期响应按请求标识丢弃；
- 事件乱序到达不影响最终状态。

## 7 集成测试

- 使用内存通道模拟 server，驱动完整事件循环；
- 输入序列 → 动作 → 请求 → 响应 → 绘制，逐帧断言；
- 覆盖打开、滚动、搜索、健康、跳转、退出；
- 断线与重连路径；
- 媒体就绪后的局部重绘。

集成测试不启动真实进程，保证在 CI 中稳定运行。

## 8 手工验证矩阵

| 维度 | 取值 |
| --- | --- |
| 终端 | Linux 终端、WSL、tmux |
| 宽度 | 120、80、60、40 列 |
| 颜色 | truecolor、256、16、无色 |
| 背景 | 深色、浅色、未知 |
| 输入法 | 中文输入、粘贴、组合键 |
| 图片 | kitty、sixel、无协议 |

手工验证记录环境、命令、结果与截图路径，不提交截图到仓库。

## 9 CI 命令

```bash
cargo fmt --all --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
cargo doc --workspace --no-deps
```

CI 使用 stable 工具链；TUI 测试在无 TTY 环境执行，全部走测试后端。
